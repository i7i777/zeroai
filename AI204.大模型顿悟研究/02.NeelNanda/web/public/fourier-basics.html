时域 → 频域

从最基础的直觉开始，讲清楚到底发生了什么

一

时域：你平时看世界的方式

时域就是：横轴是时间，纵轴是信号的大小。比如你录了一段声音，画出来是这样：

在模加法任务里，数字 a 的 one-hot 向量就是一个时域信号：

这是时域：横轴是数字索引 n，纵轴是值。

二

频域：换一个角度看同一个东西

频域是：横轴是频率，纵轴是该频率的强度。

同一个声音，在频域里可能是这样：

频域告诉你：这个信号里，各个频率的成分各有多少。

低频多

信号变化慢，波形平缓，能量集中在频谱左侧。

高频多

信号变化快，波形尖锐，能量集中在频谱右侧。

三

为什么需要频域？

因为同一个东西，在时域里难处理，在频域里可能很简单。

举个例子：两个声音混在一起，你想把它们分开。

时域视角

你看到的是两条波形叠加在一起，乱成一团，很难拆。

频域视角

你看到的是两组不同的频率峰。一个在低频，一个在高频。直接按频率切开就行。

频域把“混在一起”变成了“分开排列”。
再比如模加法 (a + b) mod 113：时域里要做进位、取模，很麻烦；频域里两个数字的旋转角度直接相加，天然取模。所以模型选择把数字搬到频域去处理。
四

怎么从时域变到频域？——DFT 的核心思想

DFT 做的事情，一句话：

拿一堆不同频率的标准波，逐个去和你的信号做匹配，看匹配程度有多高。

1. 准备一组“标准波”

对于每个频率 k = 0, 1, 2, …, 112，准备一个标准波 e^(-i·2πkn/113)。这是一个在复平面上旋转的波：

2. 拿每个标准波去“匹配”你的信号

匹配的方式是：逐点相乘，然后全部加起来。

X[k] = Σn=0112 x[n] · e−i·2πkn/113

这个操作叫内积，衡量的是：你的信号 x 和频率 k 的标准波有多像。

如果很像

X[k] 很大 → 信号含有大量这个频率。

如果不像

X[k] 接近 0 → 信号几乎没有这个频率。

3. 对所有 k 都做一遍

做完 113 个频率，你就得到了 113 个复数 X[0], X[1], …, X[112]。这 113 个数就是频域表示。

五

用 one-hot 走一遍

数字 a 的 one-hot 向量：当 n = a 时为 1，其余全为 0。代入 DFT，求和只剩一项：

X[k] = 1 · e−i·2πka/113 = cos(2πka/113) − i·sin(2πka/113)
这意味着什么？
时域里：数字 a 是一个尖锐的脉冲，只在一个位置有值。
频域里：这个脉冲变成了所有频率上都有值，每个频率 k 的“值”就是圆上的一个点。
六

为什么脉冲的频谱是“平坦”的？

直觉上：

缓慢变化的信号

比如低频正弦波，它的能量集中在低频。

急剧变化的信号

比如尖脉冲，它包含了所有频率的成分。

脉冲是“最快的变化”——从 0 突然跳到 1，再突然跳回 0。要组成这么尖锐的形状，需要所有频率的正弦波一起合作。所以脉冲的频谱是平坦的：每个频率都贡献了相同的幅度，只是相位不同。

相位就是 2πka/113，它编码了脉冲的位置 a。
• 幅度告诉你“有多少这个频率”。
• 相位告诉你“这个频率的波峰在哪里”。

对于 one-hot 脉冲，所有频率的幅度相同，但相位随 k 和 a 变化。正是这些相位，唯一地编码了数字 a。
七

八

一句话总结

时域
横轴是位置 / 时间，你看到的是信号本身的形状。
频域
横轴是频率，你看到的是各个频率成分的多少和相位。
DFT
拿所有频率的标准波去和信号逐一匹配，匹配结果就是频域表示。
one-hot 脉冲
做 DFT 后每个频率都得到相同的幅度，但相位是 2πka/113，这些相位唯一编码了数字 a。
