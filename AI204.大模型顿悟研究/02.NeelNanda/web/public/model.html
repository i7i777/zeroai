② 网络结构（论文主模型：单层 Transformer 解模加法 a + b mod P）

token(114 种：0…112 与 “=”) × 3 位置 → EMBED(输出 3×128) → ATTENTION(4 头，各自经 W_O 后 128 维 → Σ 相加) → MLP(128 → 512 ReLU → 128 输出) → logits(113 类，由 W_U·x 读出)。每个块里画的是「当前样本 × 当前权重」算出来的真实输出张量：每根竖条 = 一个分量，以中线为基准（琥珀向上 = 正，天蓝向下 = 负），高度 ∝ (|数值| / 该块最大值)0.65（幂次压缩，便于看清小分量）；logits 块条长 ∝ logit，金框 = 真值类。切换 Seed / 拖 epoch / 点「测试」换样本后自动重算。
